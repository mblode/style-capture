Common help

Quick answers

If the picker does not appear, make sure you are on a normal web page. Chrome blocks extensions from running on restricted pages such as chrome:// URLs and the Chrome Web Store itself.

If clipboard copy fails, try again on a standard page and paste into any text editor to confirm the capture output.

Use the options page to change capture depth and whether pseudo-elements or hidden elements should be included.

Use the Chrome Web Store listing support contact if direct follow-up is needed.
