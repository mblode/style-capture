Style Capture

Last updated: 2026-03-14

Style Capture is a Chrome extension that captures computed CSS from a DOM subtree the user explicitly selects on the current tab and copies a structured prompt to the user's clipboard.

Information the extension handles

When the user starts a capture, the extension may handle:

  • the selected DOM subtree's sanitized HTML,
  • computed CSS for the selected nodes,
  • pseudo-element styles if enabled,
  • local extension settings.

The extension does not include the page URL or page title in its capture payload.

How the information is used

The extension uses this information only to:

  • build the local capture requested by the user,
  • copy the capture output to the user's clipboard,
  • remember capture defaults in local storage.

Data sharing

Style Capture does not transmit captured page content, page metadata, or settings to the developer or any third party.

Style Capture does not sell data, use it for advertising, or share it for purposes unrelated to the extension's single purpose.

Retention

Capture settings remain in local Chrome storage until the user changes or clears them. Captured output is copied to the local clipboard and is not retained by the developer.

User controls

Users can decide when captures happen, what gets included, and can remove the extension at any time.

Support
