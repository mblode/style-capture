<tailwind_hints>
0=grid gap-6 p-8 rounded-[20px] bg-white

Confidence levels

  • Scale match — uses stock Tailwind tokens
  • Arbitrary value — exact value in brackets
  • Review needed — layout-derived values flagged

Open questions

Width, height, and inset values that look layout-derived are flagged so you can confirm responsive intent before committing.
